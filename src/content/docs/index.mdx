## How It Works

img2text converts images to text descriptions using vision-capable models (via cloud APIs or local inference), so your non-vision LLM in Claude Code can understand screenshots, diagrams, and photos.

<CardGrid stagger>
  <Card title="Auto-Detect Backends" icon="setting">
    Detects configured backends from environment variables. Supports Qwen, Zhipu, Moonshot, Stepfun, OpenAI-compatible, Ollama, and vLLM.
  </Card>
  <Card title="Hook Integration" icon="add-document">
    Installs a UserPromptSubmit hook that auto-converts pasted images and @mentioned files before your LLM sees the prompt.
  </Card>
  <Card title="Dual Quality Modes" icon="information">
    Fast mode for quick scans, detailed mode for deep analysis. Choose per use case.
  </Card>
  <Card title="Configurable" icon="puzzle">
    Set provider, API keys, and model preferences via CLI or edit ~/.config/img2text/config.yaml directly.
  </Card>
</CardGrid>
