img2text

Let non-vision LLMs "see" images in Claude Code.

Get Started GitHub

No Vision Model? No Problem

img2text converts images to text descriptions so non-vision LLMs can understand screenshots, diagrams, and photos.

Without img2text
const x = function(a, b) {
  return a + b
}
With img2text
const add = (a, b) => a + b;

Why img2text

⚡ Multi-Backend

Supports Qwen, Zhipu, Moonshot, Stepfun, Ollama, vLLM, llama.cpp, MLX, and any OpenAI-compatible API.

★ Auto-Detection

Auto-detects available backends from environment variables. No manual setup needed.

⇕ Hook Integration

Seamless Claude Code hook: paste images or @mention files, auto-converted to text.

⚙ Dual Mode

Fast mode for quick scans, detailed mode for deep analysis. Choose per use case.

✎ Simple CLI

Clean Click-based interface: img2text convert, img2text config, img2text list-backends.

📦 Cross-Platform

Linux with vLLM or llama.cpp, macOS with MLX, or cloud APIs. Works everywhere.
